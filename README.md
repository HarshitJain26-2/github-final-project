# Simple Interest Calculator

A simple Bash-based calculator that calculates simple interest using the principal amount, annual rate of interest, and time period.

## Description

The Simple Interest Calculator is a command-line application that helps users calculate the interest earned or payable on a principal amount over a specified period.

## Formula

Simple Interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest (percentage).
- **Time:** The time period in years.

## Requirements

- Bash shell
- A terminal or command-line interface

## How to Use

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Make the script executable:

   ```bash
   chmod +x simple-interest.sh
   ```

4. Run the script:

   ```bash
   ./simple-interest.sh
   ```

5. Enter the principal amount, annual rate of interest, and time period when prompted.
6. The script calculates and displays the simple interest.

## Example

Suppose you enter:

- Principal: 1000
- Rate: 5%
- Time: 2 years

Calculation:

```text
Simple Interest = (1000 × 5 × 2) / 100
Simple Interest = 100
```

The simple interest is **100**, and the total amount after interest is **1100**.
